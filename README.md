# Botalka — платформа подготовки к ЕГЭ с квизами и дуэлями

Тренажёр ЕГЭ, где решение задач устроено как игра: короткие квизы, дуэли 1×1 в реальном
времени, рейтинг и лиги. Первый предмет — **профильная математика**, дальше русский язык,
потом остальные.

В перспективе — ИИ-проверка сочинений и распознавание фото с решением второй части.

## Статус

Спринт 0 готов: поднимается локально, вход через Telegram работает, миграции есть.
Дальше — банк задач (Спринт 1), см. [docs/ROADMAP.md](docs/ROADMAP.md).

```bash
cp .env.example .env && make up && make migrate
```

Сайт — http://localhost:3000, API — http://localhost:8000/docs.
Подробнее в [docs/DEV.md](docs/DEV.md).

## Структура репозитория

```
backend/   FastAPI: API, WebSocket-дуэли, проверка ответов
web/       Next.js: сайт и, позже, Telegram Mini App (одна кодовая база)
bot/       Telegram-бот (aiogram): вход в Mini App, напоминания, уведомления о вызовах
content/   банк задач в YAML/JSON + скрипты импорта
docs/      планы и решения
```
