# Дизайн

Источник правды — `docs/reference/screens-v2.html`: прототип приложения (профиль,
дуэли, магазин, лидерборд, квизы, статистика, пробники, друзья, своя задача). Токены в нём те же, что были в первой версии
(`screens-v1.html`, продукт там называется «Балл» — **у нас везде «Боталка»**),
отличается композиция: плотнее сетка, крупнее заголовки, больше плиток с числами.

Оба файла самодостаточные, открываются в браузере.

## Раскладка (из v2)

Задана классами в `globals.css`, а не по месту — иначе страницы разъезжаются
по мелочи.

| Класс | Что это |
|---|---|
| `.page` | колонка секций с шагом 22px — обёртка любой страницы |
| `.page-title` / `.page-subtitle` | заголовок 29px и подпись под ним |
| `.section-title` | подзаголовок секции, 19px |
| `.tile` + `.tile-value` / `.tile-unit` / `.tile-label` | плитка с числом: пять в ряд на профиле, три на дуэлях |
| `.row-card` | строка списка: дуэли, друзья, лига |
| `.section-head` / `.section-note` | шапка секции: заголовок слева, приписка справа |

Сайдбар — 258px, пункты 14.5px со скруглением 14px. Контент — `padding: 38px 46px`,
максимум 1240px.

Карточки: радиус 20px для крупных секций, 16px для строк списка, 14px для плиток.

## Токены

Взяты из референса напрямую, менять только осознанно.

```css
--color-bg:        #FBFCFD;   /* холодный светлый фон */
--color-surface:   #F2F5F8;   /* подложка секций */
--color-text:      #14171C;
--color-accent:    #0088B0;   /* циан — всё интерактивное */
--color-accent-2:  #D6006C;   /* магента — редкий второй акцент */
--color-divider:   rgba(20,23,28,.1);
```

Шкалы `--color-accent-100…900` и `--color-accent-2-100…900` есть в референсе целиком —
переносить как есть. Ключевые из них: `#E9F8FF` (фон активного пункта меню),
`#CBEEFF` (верный ответ), `#FFF1F4` / `#FFDEE6` (ошибка, входящий вызов).

```css
--font-heading: Nunito, system-ui, sans-serif;   /* вес 600, округлый гротеск */
--font-body:    "Inter Tight", system-ui, sans-serif;

--radius-sm: 10px;  --radius-md: 14px;  --radius-lg: 20px;
--space-1: 5px; --space-2: 10px; --space-3: 15px; --space-4: 20px;
--space-6: 30px; --space-8: 40px;

--shadow-sm: 0 1px 2px  rgba(45,43,43,.14);
--shadow-md: 0 3px 10px rgba(45,43,43,.16);
--shadow-lg: 0 12px 32px rgba(45,43,43,.22);
```

Сетка десктопа — 1280. Мобильную версию референс не покрывает: раскладку придётся
придумывать, сохраняя токены.

## Правила подачи

- Светлый продуктовый гротеск: округлые карточки, капсульные фильтры, мягкие тени
- Циан — единственный цвет действия. Магента — только акценты: ошибка, входящий вызов,
  слабая тема, «до третьего места». Если магенты на экране больше одного пятна — перебор
- Крупные цифры-показатели (счёт дуэли, `8/10`, `124 дня`) — заголовочным шрифтом
- Обращение на «ты», без снисходительности. Аудитория 16–18 лет
- Из геймификации только **стрики и достижения**. Лиг, уровней и XP нет — сознательно
- Числа всегда с единицей измерения и пояснением: не «1842», а «рейтинг 1 842 · +3 за неделю»

## Продуктовые решения, зашитые в референс

Это не только про внешний вид — из макетов следует механика:

- **План на сегодня из трёх шагов** с оценкой времени («сегодня 18 минут работы»).
  Третий шаг заблокирован, пока не сделан второй — управляемая последовательность
- **Ошибки возвращаются**: собираются в разбор и приходят отдельным набором через два дня
  (интервальные повторения)
- **Наборы задач по номерам КИМ** — отдельная сущность рядом с квизами, с прогрессом
  и оценкой времени. Можно собрать свой набор из личных ошибок
- **Дуэль**: 1×1, 7 раундов, вопрос обоим одновременно, очко — за верный и быстрый ответ,
  тайбрейк по суммарному времени. Ответ блокируется до ответа соперника
- **Рейтинг только по дуэлям.** Квизы и наборы на него не влияют — иначе рейтинг
  превращается в «кто больше сидел»
- **Разбор ошибки — по шагам** (3 шага + «что запомнить»), а не одно сплошное решение
- Предметы считаются независимо: свой план, своя статистика

## Решения по референсу (12.08.2026)

- **Навигация — боковое меню** (вариант 2a), не верхняя шапка
- **Сначала десктоп.** Телефон — потом, отдельным заходом: Telegram Mini App
- **Лендинг ведёт сразу во вход через Telegram.** Гостевой режим в коде остаётся
  и работает, но главная кнопка лендинга — вход
- **Цифры на лендинге честные**, даже когда они маленькие. Задачи в банк добавляем
  в последнюю очередь, до этого не приукрашиваем
- **В квизе можно прыгать между вопросами** и пропускать
- **Подсказка не отменяет зачёт**, но задача помечается «решено с подсказкой»
- Обращение на «ты», тон без сюсюканья
- Заголовок лендинга пока оставляем из макета: «Готовься к ЕГЭ так, будто это игра
  с самим собой»

## Чего в референсе нет и надо решить отдельно

- Мобильная раскладка и Telegram Mini App
- Экран ИИ-проверки сочинения и загрузки фото
- Донаты и платные функции
- Пустые состояния: новый пользователь без статистики, пустая очередь дуэлей
- Экран учителя и класса
