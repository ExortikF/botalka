# Рейтинг

## Главное правило

**Рейтинг меняют только онлайн-матчи.** Квизы, тренировки и асинхронные дуэли по ссылке
на него не влияют — вообще.

Причина: любая другая схема ломается об абьюз. Если начислять за решённые задачи,
рейтинг станет счётчиком усидчивости, и первое место займёт тот, кто дольше сидел, а не
тот, кто лучше решает. Если считать по дуэлям-ссылкам, их можно фармить, раз за разом
вызывая слабого друга. Живой матч с подбором соперника — единственный формат, где
соперника не выбираешь.

## Формула

Обычное Эло:

```
ожидание_A = 1 / (1 + 10^((рейтинг_B − рейтинг_A) / 400))
Δ_A = K × (результат_A − ожидание_A)
```

`результат` — 1 за победу, 0,5 за ничью, 0 за поражение. Победа над сильным даёт
больше, чем над слабым; проигрыш слабому наказывается сильнее.

## Коэффициент K

| Условие | K | Зачем |
|---|---|---|
| первые 5 матчей | 40 | новичок быстро съезжает к своему уровню, а не ползёт месяц |
| дальше | 24 | рабочий режим |
| рейтинг ≥ 1600 | 16 | наверху разброс меньше, иначе одна случайность роняет на сотню |

## Границы

- Старт — **1000**.
- Нижняя граница — **100**. Бесконечное дно демотивирует: если после серии неудач
  рейтинг уходит в минус, играть уже незачем.
- Верхней границы нет.

## Ранги

Голое число мало что говорит, поэтому рядом показываем ранг:

| Рейтинг | Ранг |
|---|---|
| 1500+ | Мастер |
| 1300–1499 | Сильный |
| 1150–1299 | Уверенный |
| 1000–1149 | Ученик |
| до 1000 | Новичок |

## Что решает исход матча

1. Больше очков за раунды. Очко в раунде получает тот, кто ответил **верно и раньше**
   соперника; если верно ответили оба — очко у более быстрого.
2. При равном счёте — меньшее суммарное время.
3. При полном равенстве — ничья.
4. **Отключение = поражение.** Иначе проигрывающий будет закрывать вкладку, чтобы не
   терять рейтинг.

## Открытые вопросы

- **Гости в рейтинге.** Сейчас гость может играть онлайн и иметь рейтинг. Возможно,
  стоит пускать в рейтинговые матчи только тех, кто вошёл через Telegram, — иначе
  можно сбрасывать неудачный рейтинг, просто очистив куки.
- **Затухание** при долгом отсутствии — пока не делаем, игроков слишком мало.
- **Подбор по рейтингу.** Сейчас в очереди берётся первый попавшийся соперник:
  при десятке игроков разброс не важен, при сотнях понадобится окно по рейтингу.
