## Блокирует остальное

- **Домен и хостинг.** Без них не работают: настоящий вход через Telegram (виджет не
  принимает `localhost`), отправка ссылки на дуэль наружу, Telegram Mini App. Сейчас
  живём на отладочном входе `DEV_LOGIN`, который в проде обязан быть выключен.
- **Выключить `DEV_LOGIN`** перед первой публикацией. Это полный обход авторизации.

## Контент

- **Картинки к задачам.** Планиметрия, стереометрия и графики сейчас только текстовые —
  самый большой пробел в банке. Поле `image_url` есть, наполнения нет.
- **Рисование поверх картинки** прямо в браузере: чертёж-черновик к задаче.
- **Задачи из реальных вариантов прошлых лет** — через админку, с проставлением
  источника. Механизм готов, наполнения нет.
- **Разбор по шагам.** В макете 1h решение разбито на 3 шага + «что запомнить»,
  у нас пока один сплошной текст. Требует другого формата в банке.
- **Больше типов внутри номера.** Сейчас в шаблоне меняются только числа, тип
  рассуждения один — вариативности настоящего ЕГЭ нет.
- **Вторая часть (№13–19)** — развёрнутые ответы, нужна ИИ-проверка или ручная.

## Продукт

- **Всплывашка при получении достижения.** Сейчас достижения считаются на лету из
  попыток, поэтому момент получения не виден. Нужно хранить факт и дату выдачи.
- **Вкладка «Предметы»** заблокирована и дублирует выбор предмета внутри «Квизов».
  Либо наполнить смыслом (прогресс по предмету, сочинения), либо убрать пункт.
- **Страница рейтинга** — таблица лидеров за неделю/месяц/всё время, как в макете 1i.
  Сейчас рейтинг виден только в своём профиле.
- **План на сегодня** из макета 1b: три шага с оценкой в минутах, третий открывается
  после второго.
- **Интервальные повторения.** В макете ошибка возвращается через два дня; у нас
  отработка ошибок бессрочная и закрывается одним верным ответом.
- **Наборы задач по номерам КИМ** как отдельная сущность с прогрессом (макет 1e).
- **Профиль: показ формы** — последние 7 дуэлей полосками, как в макете.

  pub/sub, если пойдём в несколько процессов.
- **Бот-заглушка**, когда в очереди никого: отвечает по усреднённой статистике живых
