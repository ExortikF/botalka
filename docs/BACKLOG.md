## Идеи по продукту (13.08.2026)

Пять направлений, которые дадут больше всего при нынешнем состоянии:

1. **Ежедневная цель и напоминание в Telegram.** Стрик есть, но о нём никто не
   напоминает. Бот пишет вечером «серия сгорит через 3 часа, осталось 5 задач» —
   это самый дешёвый способ поднять возвраты, и вся инфраструктура уже есть.
2. **Разбор по шагам вместо стены текста.** Сейчас решение — один абзац. Разбить на
   3 шага с раскрытием по одному («что заметить» → «как посчитать» → «ответ»)
   и добавить «что запомнить». Ученик, который не понял, получает подсказку, а не
   готовый ответ.
3. **Прогноз балла.** По статистике решений показывать «сейчас ты решаешь на ~68
   тестовых баллов» с разбивкой, какие номера тянут вниз. Шкала перевода уже есть,
   данных достаточно. Это то, ради чего вообще готовятся.
4. **Режим «до первой ошибки»** и другие короткие форматы: марафон на скорость,
   пять задач по слабой теме. Разнообразие форматов на том же банке стоит дёшево,
   а от однообразия люди отваливаются.
5. **Профиль наружу, без входа.** Страница профиля есть, но открыть её может только
   вошедший. Чтобы ссылкой можно было хвастаться в чате, нужен публичный адрес и
   картинка-превью для мессенджеров.

Ещё из полезного помельче: тёмная тема (уже просили), горячие клавиши в квизе
(Enter — ответить, стрелки — навигация), «продолжить с того же места» после
закрытия вкладки.
